# Feeding Minds Initiative (FMI)

**Empowering the Next Generation of Nigerian Leaders.**

Feeding Minds Initiative (FMI) is a non-profit organization dedicated to empowering Nigerian youth through free, hands-on vocational training, mentorship, and skill acquisition. We believe in feeding the mind to unleash the future.

![Feeding Minds Initiative Hero](public/hero-main.jpg)

## 🚀 About Us

We span across Benin City, Edo State, offering practical training in:
*   **Graphic Design**: Mastering visual communication and digital tools.
*   **Shoemaking & Crafts**: Creating tangible value with skilled hands.
*   **Tech Skills**: Programming, digital literacy, and future-ready competencies.

Our mission is to create a self-reliant generation capable of driving innovation and economic growth in Nigeria.

## ✨ Features

*   **Cinematic Hero Section**: High-impact, full-bleed visuals with premium animations.
*   **Interactive Values**: Engaging presentation of our core values (Growth, Service, Impact, Excellence).
*   **Program Showcase**: Detailed view of our skill acquisition programs.
*   **SEO Optimized**: Fully optimized for search engines with JSON-LD structured data and meta tags.
*   **Responsive Design**: Flawless experience across mobile, tablet, and desktop devices.
*   **Google Analytics 4**: Integrated traffic tracking and user insights.

## 🛠️ Tech Stack

*   **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
*   **Styling**: [Tailwind CSS](https://tailwindcss.com/)
*   **Icons**: [Lucide React](https://lucide.dev/)
*   **Typography**: [Bricolage Grotesque](https://fonts.google.com/specimen/Bricolage+Grotesque)
*   **Animations**: CSS Keyframes & Tailwind Utilities

## 🏃‍♂️ Getting Started

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/YOUR_USERNAME/feeding-minds-initiative.git
    cd feeding-minds-initiative
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    # or
    pnpm install
    # or
    yarn install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    # or
    pnpm dev
    ```

4.  **Open [http://localhost:3000](http://localhost:3000)** with your browser to see the result.
